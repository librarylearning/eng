HOW TO ADD REAL VOICE RECORDINGS
================================

Put MP3 files in this "audio" folder. When a recording exists,
the website plays it instead of the computer voice.

NAMING RULE (the name must match exactly):
  - all small letters
  - words joined with a dash  -
  - no punctuation
  - ends in .mp3

  Word or sentence on screen      File name
  --------------------------      ---------------------
  coffee                          coffee.mp3
  Good morning!                   good-morning.mp3
  I'm ready.                      im-ready.mp3
  The tea is hot.                 the-tea-is-hot.mp3

LETTERS AND SOUNDS (Sound Explorer)
  letter-b.mp3   the letter's name ("bee")
  sound-b.mp3    the letter's sound ("buh")
  The computer voice is not good at single sounds, so these
  recordings make the biggest difference. Start with them.

EASY WAY: open "For Teacher" on the site. Choose a list (a story,
a word group, or the letters) and it shows every file name.

RECORDING TIPS
  - Record in a quiet room, close to the phone or microphone.
  - Speak slowly and clearly.
  - A phone voice-memo app works. If it saves .m4a files, convert
    them to .mp3 with a free converter.
  - Keep files small (under 200 KB each) so the site stays fast.
